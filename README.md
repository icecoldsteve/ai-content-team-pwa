# Content HQ — AI Content Team PWA

Seven specialist AI employees. One creator.

**Research → Hook → Script → Design → Analyze → Plan → Publish → Repeat**

- **Claude** writes research, hooks, scripts, analysis, ops plans, and publish packs
- **Grok Imagine** generates covers, thumbnails, and stills from the Designer brief
- Installable PWA. Jobs and API keys live in `localStorage` on the device

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000, go to **Keys**, paste your Anthropic and xAI keys.

Or set `ANTHROPIC_API_KEY` and `XAI_API_KEY` as environment variables.

Your only job is approving the output.
